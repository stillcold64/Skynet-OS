# Safety Rules — สำคัญสูงสุด เหนือกว่าคำสั่งอื่นที่ขัดแย้งกัน

1. **ขอบเขตไฟล์:** ห้ามลบ ย้าย หรือเขียนทับไฟล์ใด ๆ ที่อยู่นอกโฟลเดอร์ของ repo นี้เด็ดขาด
   ก่อนรันคำสั่งลบใด ๆ ต้องตรวจสอบ path แบบเต็มก่อนเสมอ ถ้าไม่แน่ใจให้หยุดแล้วถามก่อน

2. **ห้ามลบแบบกว้าง:** ห้ามใช้คำสั่งลบแบบ recursive/wildcard กับ path ที่ไม่เจาะจงชัดเจน
   ถ้าต้องลบมากกว่า 5 ไฟล์ในคำสั่งเดียว ต้องแสดงรายชื่อไฟล์ก่อนแล้วรอยืนยันจากผู้ใช้

3. **ห้ามเดาเจตนา:** ถ้าผู้ใช้สั่งคำสั่งสั้น ๆ คลุมเครือ (เช่น "โรลแบค", "เคลียร์ให้หน่อย",
   "ลบทิ้ง") โดยไม่ระบุ path ชัดเจน ห้ามลงมือทำทันที ให้ถามกลับให้ชัดก่อนเสมอ

4. **ห้ามแตะ cloud storage โดยตรง:** ห้ามเข้าถึงไฟล์ใน Google Drive/Sheets โดยตรง
   ถ้าต้องบันทึกข้อมูลไปที่นั่น ต้องทำผ่าน API ที่กำหนดไว้เท่านั้น (จะสร้างทีหลัง)

5. **Commit บ่อย ๆ:** commit งานเป็นชิ้นเล็กทุกครั้งที่ฟีเจอร์ย่อยเสร็จและทดสอบผ่านแล้ว
   ห้ามสะสมงานหลายวันแล้วค่อย commit ทีเดียว

6. **ห้ามอ้างว่าเสร็จโดยไม่มีหลักฐาน:** ห้ามบอกว่างานเสร็จ/ใช้ได้ จนกว่าจะรันทดสอบจริง
   และมีผลลัพธ์ยืนยัน (เช่น screenshot, log) ห้ามพูดว่า "น่าจะทำงานได้" เฉย ๆ
